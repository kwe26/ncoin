# NCoin (NeneCoin)
> An Virtual Currency that can be ejected out and shared across anyone on the blockchain. Via a Physical File for sharing NCoin.

# How it will work?
You will be assigned an Virtual Address that looks similar to an Bank Account Number
There will be an ATM Section, When you go to ATM, You will be asked the Amount you want to withdraw.
The ATM Checks your available Balance and if you have enough, It will eject NCoin (.png Signed Cyrptographically) and that amount will be deducted from your balance and will stay on that .PNG file. If you lost it you lost the amount. If there are multiple NCoin files, you can use them to share the amount.
